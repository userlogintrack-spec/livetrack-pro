Identify SDK
Attach real CRM context to anonymous visitors

Drop one line in your app after the user logs in:

window.LiveTrack.identify({
  email: 'bhavesh@aabhyasa.com',
  user_id: '12345',
  name: 'Bhavesh',
  plan: 'pro',  mrr: 99
});

Agent now sees the visitor's real name + traits next to every chat. Supports queued calls via window.LiveTrackQueue for async / pre-load patterns.

Email Channel
Zendesk killer
Email-to-Chat (IMAP + SMTP)
Customer emails become chats; agent replies go out via your SMTP

Connect a Gmail, Outlook, or custom-domain mailbox. Incoming emails to support@yourdomain.com arrive in your queue as chats. Agent replies go out via SMTP from your own address — the customer never knows it's not a "real" email thread.

  • Gmail: use an App Password (regular passwords won't work)
  • Outlook / Office 365: imap.outlook.com:993 + smtp.office365.com:587
  • Custom domain: any IMAP/SMTP works (cPanel, Zoho, Bluehost)
  • Automatic threading by subject + sender hash
  • Credentials Fernet-encrypted at rest
